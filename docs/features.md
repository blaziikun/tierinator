## Starting a list

The **list menu** (the open list's name, top left, or <kbd>L</kbd>) is about which list: your lists, new ones, this one
(rename, duplicate, stream mode, delete) and packs. **File** is about this list's files and the outside world: save,
load, share, export, back up, and what's kept where (About & privacy).

| Feature | What it does | Where |
| --- | --- | --- |
| Start screen | "Make a tier list", then four ways in: your own things, templates, the Pokémon pack, or a saved file. The empty board shows faintly behind it. | Shown on first visit; **Start with an empty list** skips it |
| New list | An empty list with the default tiers (SS to U), or your own default tiers if you've saved some. | List menu → **New list** |
| New Pokémon list | A list of every Pokémon; the pack loads from the site the first time. | List menu → **New Pokémon list** |
| New alignment chart | Nine cells from lawful good to chaotic evil, three across. | List menu → **New alignment chart** |
| Template gallery | Ready-made lists (planets, dog breeds, flags and more), found by search or category. | Start screen → **Browse templates**; List menu → **New list from a template…** |
| Template pictures | Opening a template fetches each item's freely licensed Wikipedia picture; the rest get text tiles. The lookup can be cancelled. | Template gallery |
| Template tiers | A template can bring its own tier names in place of the usual ones. | Template gallery |
| Template pages | Every template has its own page with its items, for search engines and for sharing. | `/t/` and `/t/<id>/` on the site |
| Template links | A link that opens the app straight into a template. | `/?template=<id>`; **Rank these** on a template page |
| Suggest a template | A form for proposing a new template, reviewed before it's added. | Template gallery → **Suggest a template**; `/t/` |
| List from a pack | Starts a list with every item of an installed pack. | List menu → Packs → **New list** |
| Switch lists | Every list, newest change first, with how many are ranked. | List menu, or <kbd>L</kbd> |
| Rename | Changes the open list's name. | List menu → **Rename** |
| Duplicate | An exact copy of the open list. | List menu → **Duplicate** |
| Duplicate, unranked | Same items, pictures and style, with everything back in the pool. | List menu → **Duplicate, unranked** |
| Delete list | Removes the open list after asking. | List menu → **Delete list** |
| Getting started tips | A short tips window, shown once after the start screen. | Automatic; ⌨ window → **show the welcome tips** |

## Adding items

| Feature | What it does | Where |
| --- | --- | --- |
| Upload pictures | One item per picture; file names become item names. | **Add items** → Upload, or <kbd>A</kbd> |
| Paste or drop on the board | Pictures pasted or dropped onto the tier list become items. | <kbd>Ctrl/⌘ V</kbd>, or drag files in |
| Type a list | One name per line, added as text tiles. | Add items → Type a list → **Add as text tiles** |
| Find a picture for each | Each typed name gets the first picture from the chosen web source; its other results become choices. | Add items → Type a list → **Find a picture for each** |
| Open a CSV | Reads Name, Tier, Position and Picture columns; names already on the list are moved, not added twice. | Add items → Type a list → **Open a CSV file…** |
| Search the web | Searches Wikipedia, anime, manga, characters, TV shows, films, albums, songs, apps, books, or countries and flags. | Add items → **Search the web** |
| Merged anime results | Anime, manga and character searches ask AniList, MyAnimeList and Kitsu at once and join matches. | Add items → Search the web |
| Pick results | Click results to choose them, or select all, then add. | **Select all**, **Add selected** |
| From a wiki | Every page of a wiki category or list page becomes an item with its lead picture. | Add items → **From a wiki** |
| Wiki options | Sub-categories one to three levels deep, tags by category, brackets dropped from names, same-name pages combined. | Add items → From a wiki |
| Wiki result filter | Filter loaded pages by name and select or clear what's shown. | **Select shown**, **Clear shown** |
| Image links | One picture link per line, optionally with a name before it. | Add items → **Image links** |
| Copy fallback | A site that blocks copies is asked through an image service; failing that, the picture shows straight from the web. | Automatic |
| Text tiles | Items with no picture show their name as a tile. | Automatic, or item editor → **Text tile** |
| Picture credits | Wikipedia and Wikimedia pictures keep their author and licence, linked to the picture's page. | Item editor, under the picture |
| Credits window | Every credited picture in the open list, to copy when you share an export. | About & privacy → **this list's picture credits** |

| Delete the selection | The same for several of your own items at once ("Deleted 3 items", with Undo). Pack items such as Pokémon can't be deleted. | Selection bar → **Delete** |

## Ranking

| Feature | What it does | Where |
| --- | --- | --- |
| Drag and drop | Drag a tile, or the whole selection, to a place in a tier or back to the pool. | Tier list |
| Auto-scroll | Dragging near the top or bottom edge scrolls to faraway tiers. | While dragging |
| Click to select | Click to select, Shift-click for a range, Ctrl/⌘-click to add from another area. | Tier list |
| Box select | Drag on empty space to select every tile inside the box. | Tier list |
| Select visible | Selects everything the pool shows now. | **Select visible** above the pool |
| Send to a tier | Click a tier's label, or press its number, to move the selection there. | Tier label, or <kbd>1</kbd>–<kbd>9</kbd> |

| Reset list | Sends everything ranked back to the pool, keeping tiers, pictures and tags. | **Reset list** above the pool |
| Quick rank | Shows the pool's items one at a time, big, with a button per tier. | **Quick rank**, or <kbd>Q</kbd> |

| Can't decide | Treats two items as equal and keeps their order. | Head to head → **Can't decide**, <kbd>=</kbd> |
| Undo and redo | Up to 80 steps of tiers, variants, deleted items, the look and the layout. | ↶ ↷, <kbd>Ctrl/⌘ Z</kbd>, <kbd>Ctrl/⌘ Shift Z</kbd> |
| Progress count | Shows how many are ranked out of the total. | Under the pool |

## Ranking together and live

| Feature | What it does | Where |
| --- | --- | --- |
| Combine rankings | Friends rank the same list and send you their share links or list files; you get the group's list. | List menu → **Combine rankings…** |
| Who's in | Paste links, add .json or .zip list files, include your own list; name or remove each person. | Combine rankings |
| Group list | Each item placed by its average position across everyone who ranked it, in the tiers most lists share. | A new list, "<title> (group)" |
| Agreement | The most agreed and most disagreed items, how many ranked each, and who was closest to the group. | Results window after combining |
| Stream mode | A clean full-screen view for ranking live on video: the tiers big and the next item shown large. | List menu → **Stream mode…**, or <kbd>V</kbd> |
| Stream options | Theme, green or magenta background for chroma key, names on or off, pool order or shuffled, from scratch or unranked only. | Stream mode options |
| Stream controls | Number keys place the item, skip and back, undo, hide the hints for camera; drag or tap a tier too. | <kbd>1</kbd>–<kbd>9</kbd>, <kbd>→</kbd> <kbd>Space</kbd>, <kbd>←</kbd>, <kbd>U</kbd>, <kbd>H</kbd>, <kbd>Esc</kbd> |

## Tiers and charts

| Feature | What it does | Where |
| --- | --- | --- |
| Add a tier | Adds a tier at the bottom and opens its editor. | **Add tier** in the top bar |
| Insert a tier | Adds a tier between two others. | **+** in the gap between tier labels |
| Move a tier | Moves a tier up or down (back or on in a chart). | ↑ ↓ (← → in a chart) beside the tier |
| Tier editor | Label, optional subtitle, colour and text colour, previewed live. | Click a tier label, or ✎ |
| Cancel edits | Closing the editor without saving puts the tier back. | Tier editor → **Cancel**, <kbd>Esc</kbd> |
| Colour palette | Swatches shared by every list; add, recolour, remove or reset them. | Tier editor |
| Text colour | Your own label colour, or the theme's. | Tier editor → **Use theme** |
| Delete tier | Deletes a tier; its items go back to the pool. | Tier editor → **Delete tier** |
| Chart layout | Lays tiers out as a grid of labelled cells instead of rows. | Style → Tiers → Layout |
| Chart columns | Two to six cells across. | Style → Tiers → Columns |
| Tile shape | Square, portrait 2:3 (posters, book covers) or landscape 16:9 (thumbnails), per list. A tile holds as much picture as the square of its size, so the size slider means the same for every shape. Tiers, pool, charts, the hover tip, stream mode and exports all follow it; undo puts it back. | Style → Shape & spacing → Tile shape |
| Picture fit | Whole picture (with space around it), or filling the tile, cropped to the centre. Text tiles always stay whole. | Style → Shape & spacing → Pictures |
| Reset tiers | Replaces the tiers with the default ones; ranked items stay by row. | Style → Tiers → **Reset tiers** |
| Use these tiers for new lists | New lists (and Reset tiers) start with this list's tier names and colours. | Style → Tiers → **Use these tiers for new lists** |
| Forget mine | New lists go back to SS to U. | Style → Tiers → **Forget mine** |

## Finding and stats

| Feature | What it does | Where |
| --- | --- | --- |
| Pool search | Filters the pool by name or number, such as #25. | Pool search box, or <kbd>/</kbd> |
| Pool order | Shows the pool in the order items were added (Pokédex order for Pokémon), A to Z, Z to A, or shuffled; choosing Shuffled again deals a new shuffle. Only the screen changes, not the ranking; saved with the list. Quick rank and stream mode follow it. | The order button beside the pool search |
| Ranked matches | Matches already in tiers are highlighted, with a button to jump between them. | **N ranked ↓** above the pool, <kbd>Enter</kbd> |
| Find bar | A floating search for when the pool is hidden, saying which tier each match is in. | **Find**, or <kbd>F</kbd> |
| Show in pool | Opens the pool with the search when the matches aren't ranked yet. | Find bar → **Show in pool** |
| Hover labels | Picture, number, name, types, sprite, tags and note beside the pointer. | **Hover: On/Off** in the top bar |
| Stats overview | Ranked counts, a tier table and a favourites card for each breakdown. | **Stats**, or <kbd>I</kbd> |
| Breakdowns | Pictures, tags and a pack's own categories; for Pokémon also type, generation, evolution stage, legendary, forms, single or dual type, body colour, base stat total, sprite game and sprite style. | Stats → menu |
| Breakdown pages | A share ring, favourites by average tier, a where-each-ended-up table and a ring per tier. | Stats → any breakdown |
| Table views | Shows counts, share of the row, or share of the tier. | Stats → **Count**, **% of row**, **% of tier** |
| Both types | Counts dual types for both, or only for their first type. | Stats → Type |

| Feature | What it does | Where |
| --- | --- | --- |

| Studio list | Search, generation and picked filters, with a picked count; hide or show it. | Left panel; **◧ List** |
| Card size | Makes the studio cards bigger or smaller. | **Card** slider |
| Fold sections | Fold a game's section away, or all of them; remembered. | Section headings; **Collapse all** |
| Pick pictures | Every picture of one of your items, grouped by where it came from. | Studio → **Pick pictures** |
| All picks | Every item with the picture it shows now. | Studio → **All picks** |
| Item filter | Search by name; all, with several pictures, merged, or no picture yet. | Studio list search and menu |
| Find more pictures | Searches the web, or the item's wiki pages, for more choices. | **Find more pictures** |
| Add pictures | Adds your own pictures as choices, by file, paste or drop. | **Add pictures**, <kbd>Ctrl/⌘ V</kbd>, drag files in |
| New item | Makes a new item from a name, ready for a picture. | **New item** |

| Export options | Labels, detail per picture, empty tiers and notes, remembered per list. | Export panel, or <kbd>E</kbd> |

| Unranked items in exports | What the pool shows (its search and filters apply), in a section under the tiers headed "Not ranked". | Export → **Unranked items** |
| Made with line | A small line in the bottom corner with the site's address, so people who see the picture can find it. On to begin with. | Export → **Made with tierinator.sayel.dev** |

| Charts in exports | A chart's cells keep their grid, labels in a band across the top. | Exports |
| Cancel export | Stops a long export part way. | Progress window → **Cancel** |
